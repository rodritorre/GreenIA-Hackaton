# Awesome DESIGN.md

Colección de ficheros `DESIGN.md` que describen el sistema de diseño de webs reales. Cada web tiene su carpeta en `design-md/<web>/`.

## Cómo usarla

1. Elige la carpeta de la web que mejor encaje con lo que se pide (lista abajo).
2. Lee `design-md/<web>/DESIGN.md` **entero** antes de escribir nada de UI.
3. Usa ese fichero como fuente de verdad de los tokens (colores, tipografías, espaciado, radios, sombras) y de los patrones de componentes.
4. Inspírate en el estilo, pero **no copies logos, nombres, marcas ni textos** de la web original.
